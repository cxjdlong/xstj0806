通讯录 · 本地版（Windows）
================================

【怎么用】
1. 把整个文件夹放到任意位置（U盘、桌面、网盘都行）
2. 双击【启动.bat】（若已打包成 contacts.exe，直接双击它）
3. 会自动打开浏览器，数据就存在本文件夹的 db\contacts.db 里
   —— 不需要任何授权点击，换浏览器、清缓存都不影响数据

【文件夹结构】
   通讯录.html / index.html  界面（已内联，双击也能离线单机用）
   contacts_local.py         本地服务（只用 Python 标准库）
   启动.bat                  双击启动（需要装 Python 3）
   打包exe.bat               双击一键打包成 contacts.exe（打一次以后不用 Python）
   db\contacts.db            SQLite 数据库（首次启动自动创建）
   backup\                  备份：全部备份的 Excel + 每天一份 .db 快照

【没装 Python？】
双击【打包exe.bat】→ 生成 dist\contacts.exe → 把 contacts.exe 拷回本文件夹
以后直接双击 contacts.exe 即可（绿色版，拷到哪数据跟到哪）

【端口】
默认 http://127.0.0.1:19118（被占用会自动换 19119、19120…，窗口里有提示）。
关掉那个黑色窗口即停止服务；数据已存在 db\contacts.db，不受影响。

【数据安全】
- 数据文件：db\contacts.db（可用 DB Browser for SQLite 打开查看）
- 备份：backup\ 目录（全部备份的 xlsx + 每天自动一份 .db 快照）
- 换电脑：整个文件夹拷走即可
